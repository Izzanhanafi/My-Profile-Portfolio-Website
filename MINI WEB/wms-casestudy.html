Warehouse Management Redesign

Streamlining core logistics operations at PT Telkom Akses using Human-Computer Interaction and Task-Centered System Design (TCSD).

Role UI/UX Researcher & Designer
Method TCSD, HCI, User Observation
Impact 100% Task Success Rate, Journal SINTA 3

The Challenge

The existing WMS at PT Telkom Akses was functional but highly inefficient. Based on field observations and interviews, warehouse staff struggled with an outdated, complex interface that led to frequent data entry errors and high cognitive load.

Key operational bottlenecks included a lack of clear navigation and the absence of a structured module for crucial tasks like Cycle Counting (stock opname). Staff had to resort to manual Excel workarounds, slowing down the entire supply chain.

The Approach (TCSD)

To bridge the gap between complex ERP functionality and actual user needs, I adopted the Task-Centered System Design (TCSD) methodology. This ensured every interface element was directly tied to a necessary task.

  • Task Identification: Mapped 6 core logistical tasks (e.g., IDO Receiving, Distribution).
  • User Persona: Created profiles based on actual staff (Pak Roni, 45, Warehouse Head) to understand frustrations.
  • Prototyping: Iterated from low-fidelity wireframes to scenario-based high-fidelity prototypes in Figma.

Interface Redesign

Focusing on clarity, reduced cognitive load, and visual hierarchy for operational environments.

New Dashboard featuring real-time data visualization and key metrics.

Streamlined Cycle Counting interface with clear step-by-step actions.

Measurable Results

The prototype was validated using the Maze usability testing platform with actual Telkom Akses warehouse staff through scenario-based testing.
